# 応用情報技術者試験 科目A CBT模擬練習（非公式）

GitHub Pagesにそのまま置ける、HTML/CSS/JavaScript製の静的アプリ。外部ライブラリ・サーバー・APIキー不要。

## 実装済み

- v3: 問題選択肢の横並び（長文は自動折り返し）、右側の見直しチェック、三段階サイズの専用電卓（±/AC/BS/00/四則）、検索・赤青黄マーカー付きメモ、図表（SVG）入りの架空ネットワーク問題
- 受験中は問題文の選択とブラウザ内のコピー/貼り付け/切り取り・右クリックをベストエフォートで抑止。**ブラウザでは画面撮影・開発者ツール・ネットワーク取得までは防げない**
- メモの「ローマ字」「かな」は入力方式の指定表示であり、**OSの日本語IME切替はできない**。キーコードだけで独自IMEは実装しない（端末/キーボードごとの差が大きいため）


- 単一回：元の問番号順またはランダム順
- 複数回：選択した回を混合してランダム出題（同一の問題文と選択肢の完全一致は重複除外）
- 選択肢：原順またはランダム（正解番号を自動追従し、元の番号も保存）
- 出題数：1～80問、時間：任意または80問150分換算
- クリックで解答／解除、前後移動、問題一覧、見直しフラグ、メモ、電卓、拡大縮小、表示幅調整
- 試験中の解答をローカルストレージに保存（ブラウザや容量制限により失敗する場合あり）
- 終了時は**点数だけを表示**し、問題と正解を画面に一覧表示しない
- 全問JSON、全問Markdown、誤答・未解答Markdown、復習依頼文コピー
- 複数の自作JSONをブラウザから読み込み可能。ユーザーが選択したファイルはアップロードされない
- 問題文・選択肢の図表画像（URLまたはファイルパス、埋込data URI）に対応

> **重要**：同梱の「オリジナル演習・第1回／第2回」は架空の練習問題です。**IPA公開過去問（2025年までの実問題）は未収録**です。過去問を使うには下記JSONを追加してください。

## GitHub Pagesへの配置

1. GitHubリポジトリを作成し、このフォルダ直下のファイルをルートに配置します。`index.html`, `app.js`, `demo-data.js`, `sets/index.json` がそのまま置かれる構成です。
2. GitHubで `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` を選び、`main` と `/(root)` を選択して保存します。
3. 公開されたURLで動作します。Pythonなどのサーバーは不要です。

個人の端末で `index.html` を直接開いた場合、内蔵のデモ問題と**ローカルJSONの読み込み**は動きます。`sets/index.json` の公開セット自動取得はブラウザ仕様上 `file://` では動かないため、GitHub PagesなどのHTTP(S)で利用してください。

## 2025年度以前の回を追加する

### パターンA：ユーザーが自作・過去問JSONを読み込む

画面の「JSONファイル（複数選択可）」から、`examples/custom-set.json` 形式のファイルを選択します。複数選択可で、単一回・複数回から選択して使えます。JSONに入力した問題はリポジトリには保存されません。

### パターンB：公開問題セットとして追加する

1. `examples/ipa-session-template.json` を参考に、回ごとの実データを `sets/ap-2025-autumn.json` 等に作成します。**テンプレートの問題文はダミーであり、正しい公式過去問ではありません。** 実際のIPA PDFの原文・選択肢・解答例と照合して入力してください。
2. `sets/index.json` に次の1件を追加します。

```json
[
  {
    "id": "ap-2025-autumn",
    "title": "2025年度 秋期 応用情報技術者試験 午前",
    "year": 2025,
    "season": "秋期",
    "sourceType": "ipa",
    "count": 80,
    "file": "sets/ap-2025-autumn.json"
  }
]
```

3. GitHubへpushすると、ページでその年度・期を選択できるようになります。ほかの年度も同様です。

**形式**：`{id,title,year,season,exam,sourceType,questions:[{id,number,topic,stem,options,answer,explanation,code?,image?,optionImages?,source?,modified?}]}`。

- `options`: 4要素の文字列配列。**ア・イ・ウ・エの原順**で登録すること。
- `answer`: 0～3の数値（0がア、3がエ）、または「ア」～「エ」。シャッフルによって正解位置を再計算します。
- `code`: プログラム・SQLなどを等幅フォントで表示（任意）。
- `image`: 画像パス/HTTPS URL/画像data URI（任意）。
- `optionImages`: 4要素の画像パス等の配列（任意）。
- `source`: IPA出典表記（例：`出典：令和7年度 秋期 応用情報技術者試験 午前 問1`）。
- `modified`: IPA問題の一部を変更しているなら `true` にする。
- `explanation`: IPA解答例にない独自解説も入力可（任意）。

`sourceType: "ipa"` で `source` がなければ出典を自動生成しますが、公開前に**表記の正確性を個別に確認**してください。

## 出力について

試験終了後のJSONには、出題順、出典、問題文、SQL/プログラム、問題画像URL、シャッフル後の4選択肢と元のラベル、模範解答、自分の解答、正誤、見直しフラグ、収録解説が含まれます。

MarkdownはChatGPT等へ渡しやすい文章形式で、全問版と誤答・未解答版があります。LLMで大量の問題を扱う場合は、**誤答・未解答版**の利用を推奨します。画像URLを参照できないLLMもあるため、図表の解析には画像自体を別途渡してください。

## IPAの著作権・公表問題の扱い

IPAが**公開した過去問題**を教材として利用する場合、IPAの条件を守ってください。通常、教育目的の問題集利用は許諾や使用料不要ですが、著作権はIPAにあります。年度、期、区分、時間区分、問番号等の出典表示が必要で、問題の一部改変はその旨明記します。

- [IPA 試験に関するFAQ](https://www.ipa.go.jp/shiken/faq.html)
- [IPA 過去問題](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html)

**現在のCBT本試験で出題された非公開問題を記録・共有しないでください。** 本リポジトリを公開すると登録した問題はインターネット上に公開されます。ユーザーがローカルJSONを読み込んだだけでは問題は公開されません。

## 安全上・技術上の制約

- ログイン・成績同期・サーバー保存機能はありません。端末間同期はできません。
- 大容量の図表画像をdata URIで埋め込んだ場合は、ブラウザの保存容量を超えて途中保存できない場合があります。
- PDFの複雑な組版や表組みを完全には再現しません。
- 問題データの事前監査・正解確認はデータ作成者の責任です。
- 模擬試験の得点率は試験本番の合否を保証するものではありません。

### 現在の公開状況

- `sets/ap-2025-spring-preview.json`：令和7年度春期・午前のうち、数式・図の画像化が不要な16問をテキスト整形した**試作版**。問題数は16問であり80問収録版ではありません。
- `sets/ap-2025-spring.json`：80問分を公式PDFから画像切り出しで自動生成する対象。`sets/index.json` に80問版が追加されている場合にのみ、公開完了したと判断できます。
- 実装上、原本画像版は選択肢のシャッフルに非対応です。テキスト試作16問は選択肢シャッフルに対応します。
